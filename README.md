# SignalApp

## 📌 Описание

SignalApp — это приложение на C# для генерации и анализа простых сигналов (синусоида и меандр) с возможностью их визуализации и сохранения в CSV файл.

Приложение реализовано с использованием WPF и архитектуры MVVM.

---

## 🚀 Возможности

* Генерация сигналов:

  * Синусоида
  * Меандр (прямоугольный сигнал)
  * Треугольная волна
  * Пилообразный график

* Параметры:

  * Амплитуда
  * Частота
  * Количество точек (100–10000)
  * Точки на период (опционально)

* Обработка сигналов:

  * Максимум
  * Минимум
  * Среднее значение
  * Количество пересечений нуля

* Визуализация графика

* Сохранение в CSV файл

---

## 🧪 Тестирование

Используется xUnit.

Покрыто:

* Генерация сигналов
* Валидация входных параметров
* Расчёты (min, max, avg) на основе математического ожидания
* Сохранение файлов и данных
