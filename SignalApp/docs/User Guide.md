# Руководство пользователя

## ▶️ Генерация сигнала

1. Введите:

   * Амплитуду
   * Частоту
   * Количество точек - Всего
   * (опционально) Количество точек - В период

2. Выберите тип сигнала:

   * Синусоида
   * Меандр

### Дополнительно:
  * Используя ПКМ можно масштабировать график
  * Используя ЛКМ двигать график

---

## 📊 Результат

Отображается:

* график сигнала
* значения:

  * max
  * min
  * avg
  * zero crossing

---

## 💾 Сохранение

1. Выберите папку
2. Нажмите "Save"
3. Файл будет сохранён в формате CSV

---

## ⚠️ Ошибки

### Неверный ввод

* амплитуда ≤ 0
* частота ≤ 0
* maxCount < 100 или > 10000

### Ошибка сохранения

* нет доступа к папке
* неверный путь
