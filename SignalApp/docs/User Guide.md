# Руководство пользователя

## ▶️ Отображение графика

1. Введите:
- Амплитуду (> 0)
- Частоту (> 0)
- Количество точек
	- Всего (от 100 до 10000)
	- (опционально) В период (от 20 до Всего)
2. Выберите Тип графика
3. Нажмите "Отобразить график"
  
### Дополнительно:
- Используя ПКМ можно масштабировать график
- Используя ЛКМ двигать график
- Используя "Назад" можно вернуться на стартовый экран

---
## 📊 Результат

Отображается:
- График сигнала
- Значения:
	- Максимальное (Max)
	- Минимальное (Min)
	- Среднее (Avg)
	- Количество пересечений 0 (Zero Cross.)
  
---

## 💾 Сохранение

1. Введите:
- Амплитуду (> 0)
- Частоту (> 0)
- Количество точек
	- Всего (от 100 до 10000)
	- (опционально) В период (от 20 до Всего)
2. Выберите папку

Сохранить все сразу

3. Нажмите "Сохранить все", чтобы сохранить сразу все возможные варианты графиков
4. Файлы будут сохранёны в формате CSV

Сохранить выбранный

3. Нажмите "Сохранить"
4. Файл будет сохранен в формате CSV
