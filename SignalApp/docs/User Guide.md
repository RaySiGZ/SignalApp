# Руководство пользователя

## ▶️ Генерация сигнала

1. Введите:
- Амплитуду (> 0)
- Частоту (> 0)
- Количество точек
	- Всего (от 100 до 10000)
	- (опционально) В период (от 20 до Всего)
2. Выберите тип сигнала
- "Синусоида"
- "Меандр"
  
### Дополнительно:
- Используя ПКМ можно масштабировать график
- Используя ЛКМ двигать график
- Используя "Назад" можно вернуться на стартовый экран

---
## 📊 Результат

Отображается:
- График сигнала
- Значения:
	- Максимальное (Max)
	- Минимальное (Min)
	- Среднее (Avg)
	- Количество пересечений 0 (Zero Cross.)
  
---

## 💾 Сохранение

Сохранить все сразу

1. Выберите папку
2. Нажмите "Сохранить все", чтобы сохранить сразу Синусоиду и Меандр
3. Файл будет сохранён в формате CSV

Сохранить выбранный

1. Выберите папку
2. Отметьте "Сохранить"
3. Выберите тип графика "Синусоида" или "Меандр"
